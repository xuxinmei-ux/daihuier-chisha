截图放置说明（投稿前请补齐，否则 README 里两张图会显示破图）

需要放两张 PNG（手机截图，建议 750×1334 或 1080×1920，命名不要改）：

1. index.png   —— 首页：定位卡（显示"已锁定"与城市/区）+ 半径选项 + 展开的「不想吃」类别 + 「转！别想了」按钮
2. result.png  —— 结果页：店名、距离（如 175m）、品类、地址 + 「导航去这里」「不服？再转一次」

拍摄建议
- 用微信开发者工具真机预览或手机截图，确保画面里**有真实餐馆名与真实距离**（证明数据来自腾讯位置服务）
- 两张图用同一台设备、同一比例，文章里并排展示更整齐
- 不要出现真实 Key、手机号、个人昵称等隐私信息

文件名固定为 index.png / result.png，README 中的引用路径为 ./screenshots/index.png 与 ./screenshots/result.png
